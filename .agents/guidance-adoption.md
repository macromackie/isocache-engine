# Guidance adoption

## Shared guidance, October 25, 2026

The selected contracts come from [Tenet Contracts v7.0.0](https://github.com/macromackie/tenet-contracts/tree/v7.0.0),
revision `286fc3ee0f05cf8db446581d072d9fcf01999de0`. Tenet 0.10 installed them from its built-in `tenet` source;
[.tenet.lock](../.tenet.lock) records each upstream path, immutable revision and hash. The catalogue links the
selected requirements that apply here.

Local adaptations scope assessment inputs and use package manifests as the dependency declaration. Store adapters
may receive the current transaction for atomic domain work. They do not own sync metadata or commit independently.
No Effect runtime, blanket type-file split, function-size quota or extra dependency manifest was adopted. Cohesive
Swift/TCA state transitions and GRDB callbacks keep their existing language and runtime boundaries.

The public `tenet-contracts.com/guidance.json` snapshot still named the earlier Tenet Factory revision
`9c7fb5d91d2701eed1aaf3b030df6cfccac9375b` when checked. The released source above is authoritative for this
adoption. Ordinary document validation and code checks remain independent of hosted model access. A provider error
leaves a model-assisted assessment incomplete; it is not a compliance result.
